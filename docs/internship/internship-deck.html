01 · Bots — the market's physics

93% of resolved markets cancel —
so every bot prices the odds of being paid.

realized EV  =  paper EV  ×  P(market resolves)
  • Measured over 9,578 resolutions: LBMA precious ~100% resolve, exchange-settled 27–40%, production 0.6%, demand ~0%
  • Conditionals score as the product of both legs
Effect: ~2× expected profit per mana. The deepest mispricings never resolve — chasing raw edge is adverse selection. This is the immune system.

  • Pipeline reproduces the published Arena board to MAE 0.18 Elo, ρ = 0.99997

04 · Thurstone — step 2: run the comparison

“When Better Choice Models Do Not Matter”

  • Thm 1 — Davidson's tie parameter provably never touches decisive predictions; the Thurstonian lattice's always does
  • The effect ceiling — an upper bound on the richer model's possible gain, computable before fitting (Thm 2 makes it sharp)
  • Result: ceiling ≤ 0.23× the practical threshold; 4 pre-registered RQs confirm — sample size matters ~26× more than link choice
  • Error budget: drift & cold-start dwarf model choice by 1–2 orders of magnitude
The retraction: an exciting +5.79 “cold-start shrinkage” effect traced to a spline-interpolation bug — true value +0.017. Self-caught, retracted, documented, real mechanism found (ridge).

04 · Thurstone — step 3: the bot rating system

The same machinery now ranks GSMC's own bots.

06 · Diffusion factor models

Generative return panels with factor structure.

  • From-scratch PyTorch implementation of Diffusion Factor Models (arXiv:2504.06566) — score-based generative returns, R = βF + ε, built for n ≪ d
  • OU forward process; score network whose bottleneck width = factor dimension k — tied orthonormal encoder/decoder = learned loadings + linear idiosyncratic skip
  • Denoising score-matching; reverse-SDE Euler-Maruyama sampling; evaluated by covariance recovery + min-variance portfolios vs Ledoit-Wolf/OAS
  • Trained on tal's real 19-asset metals panel (XAU/XAG/XPT/XPD + MB critical-minerals codes, 2018–2026)
Companion: RMT correlation denoising — Marchenko-Pastur clipping on 466 S&P stocks: 92.7% of eigenvalues are noise → OOS min-variance Sharpe 0.00 → 0.78, vol −68%.

07 · Sandbox agents — CriticalMineralsBot

The model said the market was at 98.2%.
The market was at 5.6%.

  • Framework: LLM in a Docker sandbox proposes trade intents; a deterministic host gate owns the credential and executes bounded orders
  • Built CriticalMineralsBot — lithium/cobalt/tantalum/NdPr profile, resolvability-aware rules, real SMM/GFEX data exports
  • A live dry run caught the model hallucinating the market price — a phantom 0.95-vs-0.056 edge the sizer would have traded; prompting didn't fix it
Fix: the model must echo the venue price back in a required field — rejected deterministically on >0.05 mismatch, with tests. The single --execute run then correctly declined to trade.
